### Tracks

1. **Knowledge workflows and orchestration.** Run real-estate knowledge workflows end to end with agents.
2. **Document extraction.** Leases, memos, and rent rolls.
3. **Attribution and provenance.** Trace every figure to its source.
4. **Asset and property management.** Operations, inspections, and energy.
5. **Open track.**

### Judging

Relevance, execution, use of Grok Bot and Cursor, traceable data, and practical usefulness.

## Project idea (working)

The idea is still open. One candidate is **Receipts**, which would span tracks 1–3.

Drop in a brochure, a lease, and a rent roll. Extract the key figures, cross-check them against each other and against public data (for example Land Registry Price Paid), and generate an investment memo. Every number in the memo links to the exact page and line it came from, and conflicts are flagged.

Working idea only. Treat the flow above as a proposal.
